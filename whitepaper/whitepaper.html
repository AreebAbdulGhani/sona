1Executive Summary

Sona is an Adobe Express add-on that models how different human minds will experience a design — before any human sees it — and then generates accessible variants for each of them, automatically and continuously.

Every accessibility tool on the market measures. It reads hex codes and font sizes, returns a score, and leaves the redesign to you. That approach is reactive and element-based, and it misses the thing that actually matters: accessibility is a holistic cognitive experience. A slide can pass every contrast ratio and still be unusable — too dense for an ADHD reader, too sensorially jarring for an autistic one, rhythmically broken for a dyslexic one.

Sona implements a four-layer architecture. A Cognitive Digital Twin builds a semantic graph of the live document. An Agent Swarm simulates a distinct neurotype per agent and returns live Cognitive Load Scores. A Neuroadaptive Variant Pipeline forks one master design into editable versions tuned per cognitive profile, preserving brand identity. A Portfolio Mesh applies Kubernetes-style reconciliation across an entire organization's Express projects, so one spec change heals every asset.

This document details the system architecture, data flows, security model, and implementation roadmap.

2The Core Engineering Problem

Existing tools fall into two categories, and both are inadequate.

The ruler tools — Stark, WAVE, axe DevTools, built-in contrast checkers. They measure things. They tell you blue-on-light-blue fails WCAG AA. Useful, but purely reactive, purely visual, purely element-based. No concept of cognitive load, no model of neurodivergent sensory processing, and no ability to fix what they find. You get a report, then you are on your own.

The generative tools — AI that writes alt text or suggests palettes. Better, but shallow. They see one element at a time with no context of the whole document. They will write alt text for an image without knowing the same image reappears three pages later in a changed narrative context that demands a different description. They will suggest a color without knowing it clashes with an animation on the next slide and triggers sensory overwhelm.

The reframe. Accessibility is an infrastructure problem disguised as a design problem. It needs continuous monitoring, intelligent remediation, and a systems-level view of how information flows through documents across an entire organization — not a one-time audit on a single file.

That is a solved problem in distributed systems. Sona ports desired-state reconciliation into the creative layer and treats an Express document as a microservice with a desired accessibility state.

Layer One

The Cognitive Digital Twin

Sona does not read a design as a list of elements. It builds a semantic graph of the document: reading order, hierarchy, visual grouping, saliency, information density per region, and cross-page narrative context — the fact that this image already appeared on page three, and what that means for its description here.

The twin is what makes everything downstream possible. It is the difference between checking a text box and understanding a page. Building it requires deep familiarity with the Express document object model, which is the direct product of shipping three prior Express add-ons.

Layer Two

The Agent Swarm

Rather than one monolithic checker, Sona deploys specialized agents that each model a specific neurotype and report against the twin. Scores update live in a side panel as the user designs — a fitness tracker for the design's inclusivity. Add too many elements and the ADHD score spikes before the layout is finished. Push a gradient too hard and the Sensory score rises, with a calmed alternative offered that holds the brand.

AgentModelsMethod
AttentionADHD focus patternsTransformer-based attention mapping — predicts where the eye lands, bounces, and gets lost in clutter.
SensoryAutistic sensory processingDetects color temperature, pattern density, and motion frequency likely to cause overwhelm.
ReadingDyslexic text parsingMeasures cognitive load, saccade patterns, and paragraph entropy.
VisionLow vision, CVD, AMDGoes past contrast ratios to model acuity loss, color blindness, and age-related macular degeneration.

Agents run in Web Workers off the main thread. Keeping a live cognitive simulation swarm from freezing the browser is an orchestration and back-pressure problem — the same class of problem as scheduling work across a cluster.

Layer Three

The Neuroadaptive Variant Pipeline

On publish, Sona forks the master design into variants optimized per cognitive profile — generated as fully editable Express pages, never a black box export.

VariantTransformation
ADHDStrips decorative clutter, sharpens visual hierarchy, adds anchor points so attention flows.
AutismReplaces unpredictable patterns with consistent grids, mutes sensory-heavy color, smooths transitions.
DyslexiaAdjusts font metrics, breaks long paragraphs, opens line spacing — message unchanged.
Low VisionScales up, maximizes contrast, simplifies layout while preserving brand.

Brand identity is a hard constraint, not a suggestion. When the Sensory Agent needs a calmed background or the Reading Agent needs new heading structure and visual separators, the pipeline calls Adobe Firefly to generate assets that stay inside the brand system.

Layer Four

The Portfolio Mesh

Every other tool assumes one file in isolation. Sona scans a team's entire Express project set and builds a unified accessibility knowledge graph — surfacing systemic findings: your whole sales deck series uses a font that fails dyslexia standards, or your Q3 social campaign has a contrast defect across seventeen posts.

Requirements are declared once in an a11y-spec.json. When legal updates the rules, or WCAG 3.0 finalizes its cognitive standards, a control loop diffs desired state against every design in the portfolio and heals the drift. This is GitOps reconciliation, applied to creative assets for the first time.

4Data Flow

A typical authoring session proceeds as follows.

  1. The user designs normally in Express. The Cognitive Digital Twin incrementally rebuilds the semantic graph as the canvas mutates.
  2. The Agent Swarm re-scores the affected regions off-thread and streams updated Cognitive Load Scores into the side panel.
  3. A score crosses threshold — information density spikes the ADHD score. Sona warns in place and proposes a remediation that respects the brand system.
  4. The user hits Generate Variants. The pipeline forks the master into neuroadaptive versions, calling Firefly where new assets are required.
  5. The user reviews each variant as an ordinary editable Express page, tweaks, and exports.
  6. For teams, the Portfolio Mesh registers the design against the shared a11y-spec and keeps it compliant as requirements evolve.

Prediction, not just measurement, is the point: the cognitive experience is known before a single human sees the design.

7Business Impact

Express is seen today as a tool for social creators and marketing teams. That market is large, and it excludes every industry where accessibility is not optional. Government agencies need Section 508 compliance. Public universities need ADA compliance for course materials. Hospitals need patient-facing documents that work for elderly users with low vision and cognitive decline. Enterprises need DEI commitments that are actually verifiable. These organizations avoid consumer design tools and cannot absorb the cost of external audits to certify creative output.

Sona makes Express the most inclusive design platform on the market — and therefore usable by all of them. Beyond market expansion, every healing operation is a potential Firefly consumption event: a calmed background for the Sensory Agent, new heading structure for the Reading Agent. And once a team encodes its personas and compliance rules into Sona, that configuration becomes organizational knowledge that does not port elsewhere.

Strategically, it positions Adobe as the leader in ethical AI and inclusive design. In a market racing to generate flashier visuals faster, Adobe becomes the company ensuring those visuals can be experienced by every human mind — a narrative that lands with enterprise buyers, educators, regulators, and the creative community alike.

8Why This Is Hard to Copy

The differentiator is the altitude. Rulers work at the element level. Sona works at the cognitive systems level, and each capability compounds on the last: the twin makes the swarm possible, the swarm makes variants possible, variants make the mesh worth having.

Canva's bulk create forks a design from a CSV. Sona forks a design from human cognition. That is a different category, not a better feature.

The moat is an intersection of skills that rarely co-occur. Building a semantic graph of a dynamic canvas requires deep knowledge of the Express document model — the product of three shipped Express add-ons. Running a multi-agent cognitive simulation swarm without freezing the browser requires the orchestration and back-pressure instincts earned managing Kubernetes clusters and CI/CD pipelines. Designing a generative variant system that respects brand identity while adapting per neurotype requires the template and workflow engine experience gained building a no-code platform. A frontend developer cannot build the infrastructure; a backend engineer cannot navigate the canvas. That intersection is the moat.
