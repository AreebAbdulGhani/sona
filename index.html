01 — The Problem

A score is not an answer.

Today's tools treat your design as a dead object to be measured. You finish the deck, you run the checker, it returns a number, and you are on your own to figure out how to fix it. That is broken twice over: it is reactive, because by the time you run the check you have already built the problem in — and it is element-based, because it looks at each text box in isolation.

Accessibility is not a property of elements. It is a holistic cognitive experience. A slide can pass every contrast ratio and still be unusable — too dense for an ADHD reader, too jarring for an autistic one, rhythmically broken for a dyslexic one. No ratio catches any of that.

Accessibility is an infrastructure problem wearing a design problem's clothes. It needs continuous monitoring, intelligent remediation, and a systems-level view of an entire organization's assets. That is what Sona is.

Measure and report

02 — The Swarm

Four agents. Four minds.

Instead of one monolithic checker, Sona deploys specialized agents that each model a specific neurotype — running off the main thread so the canvas never stutters. Scores update live as you design, like a fitness tracker for your design's inclusivity.

Attention

ADHD

Transformer-based attention mapping predicts where the eye lands, where it bounces off, and where it gets lost in visual clutter.

Sensory

Autism

Models sensory processing to catch color temperatures, pattern densities, and motion frequencies that cause overwhelm.

Reading

Dyslexia

Simulates text parsing to measure cognitive load, saccade patterns, and paragraph entropy — the reading rhythm no ratio sees.

Vision

Low vision · CVD

Goes far past contrast ratios to model acuity loss, color blindness, and age-related macular degeneration.

03 — The Architecture

Four layers. One control loop.

Sona ports DevOps primitives into the creative layer: an Express document becomes a microservice with a desired accessibility state.

01

Cognitive Digital Twin

A live semantic graph of the document — reading order, hierarchy, saliency, information density, and cross-page narrative context. It knows that this image already appeared on page three and that its description here must change. The difference between checking a text box and understanding a page.

semantic graph reading order saliency map density field
02

Agent Swarm

Attention, Sensory, Reading, and Vision agents score the twin continuously and stream a Cognitive Load Score per neurotype. Add too many elements and the ADHD score spikes before the layout is even finished. Push a gradient too far and Sona offers a calmed alternative that keeps your brand.

Web Workers live scoring predictive persona
03

Neuroadaptive Variants

One master design forks into versions tuned per cognitive profile: clutter stripped for ADHD, patterns regularized and color muted for autism, font metrics and rhythm adjusted for dyslexia, scaled and simplified for low vision. Generated as fully editable Express pages — never a black box. Firefly supplies new assets that stay inside your brand system.

ADHD Autism Dyslexia Low Vision brand-locked
04

Portfolio Mesh

Every other tool assumes one file in isolation. Sona scans your team's whole project set and builds one accessibility knowledge graph — your entire deck series uses a font that fails dyslexia standards. Declare requirements once in a spec; when the law changes or WCAG 3.0 lands, a reconciliation loop heals every design you own.
